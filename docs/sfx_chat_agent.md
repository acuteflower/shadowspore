# SFX-Auftrag für den Claude-Chat-Agenten (Higgsfield)

Du erzeugst die noch fehlenden Soundeffekte für das Spiel *Shadowspore* (dunkles Pixel-Art-Märchen, keine Musik, keine Sprache). Aus Claude Code geht das nicht mehr (Gratis-Kontingent dort gesperrt, Credits 0), im Chat schon.

## Regeln
- Modell: `seed_audio`, `use_unlim: true`, `format: "wav"`, `sample_rate: 44100`. Jeder Prompt unten ist **wortwörtlich** zu übernehmen (alle Sounds teilen die gleiche Basis, nur so klingen sie zusammenpassend). Nichts umformulieren, nichts weglassen.
- **Immer nur ein Job gleichzeitig** (parallel gibt Fehler 429). Danach mit `jobs_wait` (timeout_seconds höchstens 15) abfragen, bis `completed`. Die Warteschlange braucht etwa 7 Minuten pro Job.
- Ergebnis-URL (`result_url`) herunterladen und als `<raw-name>.wav` in einem Ordner speichern, z. B. `sfx_raw/` (Namen unten in Fettschrift).
- Credits nicht ausgeben. Wird `use_unlim` abgelehnt: stoppen und melden.

## Packs (mehrere Sounds in einem Clip)
Ein Clip enthält 2-3 Sounds hintereinander mit etwa einer Sekunde Stille. `tools/sfx_process.py` schneidet sie an den Stillen auseinander (Abschnitt `packs` in `tools/sfx_manifest.json`). Das spart Wartezeit.
- Das Skript meldet pro Pack `N pieces for M ids`. Stimmen die Zahlen nicht, den Clip einmal neu erzeugen. Klappt es wieder nicht: die Einzel-Prompts (Abschnitt „Einzeln") der betroffenen Sounds nehmen.
- Reihenfolge: Tiere zuerst (pack_small, pack_deerfox, pack_bear, pack_crow, pack_raven, pack_birds2), dann UI und Bauen (pack_ui1, pack_ui2, pack_build, pack_misc), dann die Schleifen.

## Danach (im Projektordner; ohne Shell-Zugriff dem Nutzer die Rohdateien mit genauen Namen geben)
```
py -3 tools/sfx_process.py <pfad-zu-sfx_raw>
Godot --headless --path . --import
```
Das schneidet, filtert und pegelt alle Dateien und legt sie nach `assets/audio/sfx/<id>.wav`. Schleifen (`loop: true`) werden nahtlos überblendet. Der Prozessor liest wav und mp3.
